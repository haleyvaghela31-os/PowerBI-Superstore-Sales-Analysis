# Superstore Sales Analysis Dashboard

## Overview
An interactive Power BI dashboard built using the Sample Superstore dataset to analyze sales performance, profitability, and regional trends.

## Tools Used
- Microsoft Power BI
- Power Query / Data Preparation
- DAX Measures
- Data Visualization

## Key Features
- KPI cards for Total Sales, Total Profit, Total Orders, and Total Customers
- Monthly sales trend analysis
- Sales and profit comparison by category
- Regional sales distribution
- Top 10 states by sales
- Interactive Year and Region slicers

## Key Learnings
- Creating DAX measures
- Building interactive reports
- Using slicers and visual filters
- Presenting business insights through dashboards

## Dataset
Sample Superstore dataset used for learning and analysis.( "Superstore.csv")
